How the refiner works

  1. Restore. PGL-Net-T predicts the first clear image. The main network stays frozen.
  2. Read features. Hooks read the H/4 and H/8 backbone features. The branch also receives the hazy input, base output, residual and a dark-channel transmission proxy.
  3. Refine. A DC/low-frequency calibrator and Fourier blocks at H/4 and H/2 predict a bounded image correction.

84,465 trainable refiner parameters in the released Track 2 checkpoint.

Training overlap and validation

Track 2 used 1,304 training pairs and 102 validation pairs. Among the 1,304 pairs, 399 share a byte-identical clear reference with the test set. The frozen backbone uses the official RW²AH checkpoint. The refiner checkpoint was selected on validation PSNR.
